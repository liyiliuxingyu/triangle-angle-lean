## 主要结论

所有角度均以度为单位。设三角形的最小角为 $m$，最大角为 $M$，已知的任意一个内角为 $x$。下表中的“三类均可能”表示：对该范围内的**每一个确定度数**，分别存在满足条件的锐角、直角、钝角三角形。

| 已知条件 | 可以推出的结论 |
| --- | --- |
| 最小角 $0\lt m\lt 45$ | 三类均可能，不能唯一判定 |
| 最小角 $m=45$ | 锐角或直角三角形均可能 |
| 最小角 $45\lt m\le60$ | 一定是锐角三角形 |
| 最大角 $60\le M\lt 90$ | 当且仅当是锐角三角形 |
| 最大角 $M=90$ | 当且仅当是直角三角形 |
| 最大角 $90\lt M\lt 180$ | 当且仅当是钝角三角形 |
| 任意内角 $0\lt x\lt 90$ | 三类均可能，不能唯一判定 |
| 任意内角 $x=90$ | 一定是直角三角形 |
| 任意内角 $90\lt x\lt 180$ | 一定是钝角三角形 |

最小角、最大角、任意内角的可行范围分别为 `0 < m ≤ 60`、`60 ≤ M < 180`、`0 < x < 180`。不存在仅凭一个可行的最小角度数就一定判定为直角或钝角三角形的情形；也不存在仅凭一个任意内角的度数就一定判定为锐角三角形的情形。

“已知类型，求角度范围”是另一个方向。例如：

$$
\text{锐角三角形}\Rightarrow 0\lt m\le60,\qquad
\text{直角三角形}\Rightarrow 0\lt m\le45,\qquad
\text{钝角三角形}\Rightarrow 0\lt m\lt 45.
$$

这些最小角范围的逆向推理不能直接成立。正文分别证明存在命题与全称命题，并列出错误逆命题的反例。

## 形式化范围

`Triangle` 是满足 $0\lt a\le b\le c$ 且 $a+b+c=180$ 的有序实数角度三元组。`HasAngle t x` 表示 $x$ 等于其中任意一个角，`ofAngles` 将三个正角排序并证明各角仍被保留。证明覆盖可行范围内的实数度数，不只是整数例子。

Lean 形式化针对上述**数值角度模型**。正文另有将满足条件的角度三元组实现为平面三角形的书面证明，该几何实现说明及部分辅助讲解并非额外的 Lean 声明。书中逐项索引了已形式化的 57 个定理。
